## Повторная очистка

Безопасная утилита (по умолчанию **только просмотр**):

~~~sh
python3 scripts/refactor/cleanup_generated_artifacts.py
~~~

Фактическая очистка при повторной необходимости:

~~~sh
python3 scripts/refactor/cleanup_generated_artifacts.py --apply
~~~

Утилита жёстко ограничена путём Refactor, исключает локальные DB/secret-маркеры и удаляет только устаревшие артефакты известного типа. Не запускать при изменении путей без ревью. Не заменять на `git clean -fdx` или массовое удаление `.git` / `node_modules` / БД.

# Локальная обработка фотоальбомов

Для альбомов используется отдельный Sharp-обработчик (`scripts/refactor/local-gallery-media-worker.ts`), а не Feed Media V2. Без него после подтверждения загрузки фотография остаётся в состояниях `uploaded` / `pending`, хотя HTTP/JS-ошибки отсутствуют.

Локальный обработчик разрешает только Refactor WORK PostgreSQL на 127.0.0.1:55921 (`gafus_refactor_real_work_20261024`) и приватный MinIO на 127.0.0.1:9000 (`gafus-refactor-gallery-test`). При любом другом окружении он аварийно останавливается. Источники, отсутствующие в локальном MinIO, не изменяет. Режимы `--once` и `--serve`. При обычном запуске `scripts/refactor/local-feed-media-worker.ts --serve` галерея стартует автоматически в том же окружении; отдельно запускать её при следующем старте не требуется. Для самостоятельного запуска нужны локальные переменные окружения API, без Cloud.ru/production-ключей.

В Web запросы чтения списка фотографий и статуса загрузки ограничены 15 секундами. При ошибке фоновый опрос прекращается, пользователь может запросить повторную проверку. Очередь использует стабильную ссылку на `onRefresh`, чтобы перерендеры списка не сбрасывали таймер проверки обработки.

## Mobile parity (29.10.2026)

Mobile использует тот же `/api/v1/gallery` и тот же приватный Gallery S3 → Sharp → WebP-пайплайн, что Web; локальный Gallery Worker обслуживает обе платформы. `apps/mobile/src/features/gallery` теперь:

- продолжает опрос `uploaded`/`processing` до `ready`/`failed` и обновляет список фотографий;
- прекращает автоматические запросы после ошибки проверки и показывает пользователю ручной повтор;
- ограничивает прямой S3 POST двумя минутами, не интерпретирует потерю ответа или abort как подтверждённый отказ и не повторяет потенциально совершённую запись;
- оставляет неподтверждённый upload в состоянии `unknown`, запрещает новые записи до сверки или отмены, сохраняет возможности проверить статус и отменить;
- показывает предупреждение, если обработка продолжается больше минуты, без фиктивной отметки успеха.

Регрессии: `queue.test.ts`, `UploadControls.g1-mounted.test.tsx`, `GalleryFlow.g1-mounted.test.tsx`. Автотесты и typecheck не заменяют проверку на реальном Android/iOS с доступным локальным API и Gallery Worker.

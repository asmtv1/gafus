## Changes in this slice

- Replaced the shared favorites query key with an owner+authEpoch key and verified-session checks before/after network. AuthProvider clears memory on epoch change even for the same account, and staggered prefetch requires a verified actor. Offline durable data remains intact.
- Private S3 fallback can never produce a disk-cache key even if called outside CdnImage. Signed CDN key generation requires expiry to cover the whole reusable window plus 15s; existing public immutable long-lived gate stays. Near-expiry URL may render memory-only; do not claim speed benefit without measurement.
- Source inventory includes exact line numbers per candidate and policy families; dynamic key/TTL values and provider runtime settings are intentionally not guessed. Redis coordination, durable queues, offline journals and capability URLs are not ordinary disposable caches.
- Do not activate flags or purge production from this document. Required QA: two API processes with delayed invalidation and stale corpus; two browser tabs with role/account changes; device offline A→B→A; real Redis/PG failures; CDN revocation, signed capability expiry, physical cache behavior. Full mounted/native/release test and benchmark not replaced by source scan.

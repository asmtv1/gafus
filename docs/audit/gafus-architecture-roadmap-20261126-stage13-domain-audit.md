## Исправления текущего прохода

- Consent: удалены неиспользуемые createConsentLogs, linkConsentLogsToUser, markConsentLogsFailed (tracked + untracked source scan; только definitions и прежние unit tests). Только completion в транзакции регистрации. Conditional updateMany + create с unique constraint, owner обязателен, существующие COMPLETED и чужие receipts не перезаписываются. Исторические строки не удалены.
- OTA: transaction-level advisory locks в двух namespace, фиксированный порядок event → installation, ReadCommitted; уникальный конфликт не считается replay. Добавлены realpg fixtures для одновременного replay/conflict/quota. Лимит 150 сохраняется; авторизация нативного release и HMAC не менялись.
- Trainer AI: нормализация нечисловых параметров, проверка безопасного offset/take и count-before-page; чрезмерный offset не передаётся в SQL при отсутствии страницы. Не введён лимит на объём доступной истории. Дополнительная последовательность запросов для непустой страницы требует замера при подключении транспорта.
- Streak: целочисленный civil-day ordinal с сохранением существующего local calendar policy, устранение 23/25-hour DST bug, игнорирование будущего дня для current streak, снятие произвольного cap 365.
- Добавлены регрессии OTA metric allowlist и distinction empty/unavailable; исправлена UTC fixture при проверке CDN metrics. Не изменялись алерт-пороги и prod-конфигурация.

## Implemented

1. Architecture check in check:core-boundaries, synthetic scanner regression test, 15 Core-to-types imports replaced with public @gafus/types.
2. Hono request correlation and bounded Prometheus HTTP counters and latency histogram, protected internal metrics endpoint. API request trace persisted in new Chat2 transactional outbox events via AsyncLocalStorage.
3. Node-only @gafus/logger/server-telemetry using official OpenTelemetry SDK, configurable bounded sampling and batched OTLP HTTP exporter, no raw private message or object URL attributes. It is NOT exported through the browser/mobile logger root. Chat2 Worker dispatch and Hono requests create spans with operation and trace IDs.
4. Worker dispatch spans also cover outgoing Cloud.ru IAM and job.execute calls, recording only phase and HTTP status, never credentials or request URLs.
5. Expand-only Prisma migration 20261107054000_chat2_outbox_lease_fencing_dlq adds claimToken UUID, operationId, traceId, lastErrorCode, deadLetteredAt and index. Worker uses a new UUID per claim and conditional update matching owner token for completion and failure; for long-running deletion it renews only its own active claim every ten seconds (heartbeat), and stops further dispatch if lease ownership is lost.
6. Eight bounded attempts, jitter, Retry-After, terminal broker 400/401/403/404 classification, sanitary error codes and durable dead letters. At-least-once delivery with stable eventId, not falsely promised exactly-once.
7. Persistence-layer Chat2 DLQ listing and conditional per-event retry behind @gafus/chat-server/outbox-diagnostics, API ADMIN-only endpoints and admin panel on the existing media screen. No private content in list; no unsafe bulk retry.
8. Worker pending/oldest/leased/dead-letter metrics, new Grafana Operations & Reliability dashboard, alerting rules and Alloy authenticated API scrape with runtime-only API_METRICS_KEY.
9. Existing media Jobs and CDN fallback contracts left untouched. Photo Jobs NOT reintroduced.

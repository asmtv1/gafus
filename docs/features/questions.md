# Вопросы

Раздел доступен зарегистрированным пользователям. Web: `/questions`, пункт после «Чат». Mobile: «Меню» → «Вопросы», маршруты вне основной панели вкладок.

## Архитектура

- `packages/core/src/services/questions`: доступ, валидация, лимиты, транзакции, обсуждения, фото, реакции, лучший ответ, закрытие, жалобы, блокировки и уведомления.
- `packages/types/src/questions.ts`: DTO, константы и общий клиент с внедряемым транспортом.
- `packages/questions-server`: общий HTTP-адаптер для Next Route Handler и Hono. Web передаёт NextAuth actor и проверяет CSRF; API передаёт JWT actor.
- Web/mobile отвечают за представление, состояние формы и транспорт. Admin Server Actions вызывают core.

## Поведение

Шесть согласованных категорий, до пяти свободных тегов и пяти фотографий JPEG/PNG/WebP по 10 МБ. Видео не поддерживается. Заголовок — до 150 символов, текст — до 10 000. Лимиты публикаций: 5 вопросов за последние 24 часа, 30 ответов за час. Удалённые публикации учитываются в лимитах.

Ответы имеют один визуальный уровень вложенности; при ответе на ответ сохраняется адресат. Сердечко можно снять; собственный ответ оценить нельзя. Автор вопроса и администратор выбирают лучший ответ. Закрытие/открытие обсуждения — отдельное действие. Удалённый ответ с дочерними ответами становится заглушкой. Поиск по заголовку/тексту, фильтры категории/статуса/своих вопросов, сортировки списка и ответов с закреплением лучшего ответа.

Жалобы поступают в admin-panel, очередь показывает текст и фото. Блокировка ограничивает публикации только в этом разделе. Уведомления о новых ответах, ответах на комментарий и выборе лучшего ответа записываются в транзакции публикации; worker добавляет задачи push каждую минуту. Реакции уведомлений не создают. Непривязанные фото очищаются через сутки.

## Проверка 2026-10-07

- 16 интеграционных тестов core прошли на отдельной PostgreSQL `gafus_questions_qa`: доступ, идемпотентность, конкурентные лимиты, права, вложенность, реакции, лучший ответ, закрытие, удаление, блокировки, атомарные уведомления и отсутствие взаимной блокировки при параллельных ответах.
- 6 тестов HTTP-адаптера прошли.
- SQL `20261007030000_community_questions` применён к отдельной БД с исходной схемой. `prisma migrate diff --exit-code` сообщил `No difference detected`.
- Первичные проверки типов web/mobile/API/admin прошли. После освобождения среды финальная проверка типов core прошла. Финальный повтор проверки web после последних исправлений остановился по таймауту; полная повторная проверка клиентов и worker не завершена. `git diff --check` прошёл.
- Актуальные визуальные проверки web/native не завершены: браузер и Simulator возвращали таймауты и не смогли загрузить новые экраны. Старые скриншоты не использованы как подтверждение. Финальное UI-ревью остаётся `recapture`.
- Реальная загрузка в CDN и доставка push на устройства не проверены. Production-миграция, deployment и выпуск приложения не выполнялись.

# Видимость питомцев в публичном профиле

У каждого питомца есть `Pet.showInProfile`: `Boolean NOT NULL DEFAULT true`.
Миграция `20261010170000_pet_profile_visibility` включает настройку для существующих
питомцев; новые питомцы получают её по умолчанию. Перед выпуском серверного кода
нужно применить миграцию обычным процессом деплоя.

В Web и Mobile переключатель «Показывать в профиле» расположен в карточке раздела
«Питомцы», доступен без раскрытия карточки и сохраняется сразу. Во время запроса
он заблокирован; при ошибке возвращается предыдущее значение и выводится сообщение.
Изменение доступно только владельцу через существующее обновление питомца.

`getPublicProfile` отбирает только видимых питомцев и возвращает для них только
`id`, `name`, `type`, `breed`, `birthDate`, `photoUrl`. Публичные карточки показывают
фото, кличку, вид, породу, возраст. Если список пуст, секция не выводится.
Публичные HTTP-ответы имеют `Cache-Control: no-store`.

Личный Web-раздел «Питомцы» получает все записи через `getUserPets`, независимо от
публичной настройки. Собственная вкладка «Профиль» из меню остаётся без питомцев.
В Mobile данные питомцев и публичного профиля обновляются при фокусе экрана;
после переключения инвалидируется соответствующий кеш. Публикации, вопросы,
альбомы и фотографии переключатель не изменяет.

## Проверка

- `apps/api/src/routes/v1/pets.route.test.ts`: авторизация, boolean-валидация,
  передача `false`, отказ для чужого питомца.
- `packages/core/src/services/pets/petProfileVisibility.integration.test.ts`:
  настоящий PostgreSQL, включение по умолчанию, скрытие/возврат, сохранение полных
  данных владельца и настройки при редактировании, белый список публичных полей.
  Требует `PET_PROFILE_TEST_DATABASE_URL`, разрешён только локальный
  `gafus_pet_visibility_test`. Запуск из `packages/core`:
  `vitest run --config src/services/pets/pet-profile.vitest.config.ts`.
- `PublicPets.test.tsx`: посетителю показываются питомцы, владельцу на вкладке
  профиля не показываются, пустая секция отсутствует.
- Визуальные проверки компонентов: Web 390/1440 px и iPhone 17, локальные
  тестовые данные; успешное сохранение и откат при ошибке. Они не заменяют
  проверку опубликованного приложения с реальным API.

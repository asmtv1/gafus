**Chat 2.0 — ответы и реакции на сообщения (29.10.2026).** Web: постоянно видимые «↩ Ответить» и «☺ Реакция» на каждом сообщении, меню по правому клику, эмодзи и счётчики под конкретным сообщением. Native Mobile: нажатие или удержание на сообщении открывает нижнюю панель с реакциями/ответом/действиями; свайп вправо отвечает на выбранное сообщение. Ответ использует прежний `replyToId`. Новое API `POST /api/v1/chats/:id/messages/:messageId/reaction` с одним из шести эмодзи (👍 ❤️ 😂 😮 😢 👏); повторное нажатие снимает реакцию, смена заменяет свою, права доступа и существование неснятого сообщения проверяются сервером. Схема `Chat2MessageReaction` уникальна по `[messageId,userId]` с каскадным удалением; миграция `20261029163000_chat2_message_reactions`, применяется к production **только отдельным согласованным процессом релиза**. В локальном Refactor применена исключительно к isolated DB snapshot на `127.0.0.1:55921`. Реакции отдаются вместе с историей, изменения публикуются через существующий outbox `message.reacted`. Проверки: переключение/снятие, чужой чат, удалённые сообщения, отображение и Web/Mobile.

**Chat 2.0 — общий чат по умолчанию (29.10.2026).** При первом авторизованном запросе списка чатов на Web или Mobile Backend идемпотентно присоединяет пользователя к единому публичному `COMMUNITY/global` («Общий чат GAFUS»), если нет уже сохранённого членства, добровольного выхода или блокировки. В списке чат закреплён наверху; отдельного ярлыка в нижней панели Web больше нет. При первом подключении история остаётся доступной, но старые сообщения не считаются новыми. Выход сохраняется как скрытое членство без автоматического повторного вступления; вернуться можно через «Найти сообщества». Блокировка `BANNED` автоматически не снимается. **Аватары отправителей на Mobile**: `apps/mobile/src/features/chat2/Chat2RoomScreen.tsx` и `Chat2Avatar.tsx` используют `room.members[].avatarUrl` по `message.authorId`; вместо безусловного `👤` показывают реальную фотографию и используют `👤` только при отсутствии/ошибке загрузки. URL проверяется (HTTP(S), без credentials). Реализация: `apps/api/src/modules/chat2/service.ts`, `apps/web-vite/src/features/chats/Chat2Messenger.tsx`. Проверять на существующем и новом аккаунте, при массовом списке, выходе и повторном вступлении, в Web/Mobile.

В таблице короткие имена файлов (`courses.ts` и подобные) относятся к `apps/api/src/routes/v1/`, если не указан иной путь. Неподтверждённые сервисы, старые планы и UI-mock не считать production-путями.

**Для агента:** перед изменением домена открой соответствующий contract/feature и фактические код/тесты; после изменения обнови справочники, матрицу QA и доказательства ретеста. Не удаляй исторические evidence без реальной необходимости.

**Безопасная рекомендация — не создавать коммит из общей рабочей копии.** Сначала сохранить внешнюю резервную копию текущего `git diff`/полного списка untracked и согласовать владельцев. Затем использовать отдельный worktree/branch от зафиксированного HEAD, переносить **строго отобранные** новые файлы, применить `git add -p` к смешанным hunk только после проверки, не применять `git add -A`, `git add .`, `git add scripts/qa` или широкие маски. До любого будущего коммита проверить `git diff --cached --name-status`, `git diff --cached --check`, **полный** `git diff --cached`, отсутствие `.env`, токенов, `.qa`, Playwright artifacts, а также frozen install/контрактные тесты в чистом дереве. Никакого staging/коммита в этой работе не было.

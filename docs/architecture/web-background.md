# Общий фон web

Единственный источник фона страниц — `apps/web/public/styles/site-background.css`.
В нём задаются изображение (`--app-background-image`), базовый цвет
(`--app-background-color`) прозрачность (`--app-background-opacity`) и размытие (`--app-background-blur`).
Текущие значения из mobile: opacity 0.27, blur 6.4px (на 20% меньше mobile blurRadius 8), основная подложка #E6E2D8.
Экраны авторизации используют #F5F0E5 через маркер `data-app-background="auth"`.
CSS-размытие и нативный blurRadius могут немного отличаться по виду на разных платформах.

Корневой `apps/web/src/app/layout.tsx` подключает этот файл для всех Next.js
маршрутов. Статические HTML-документы в `apps/web/public` подключают ту же
таблицу стилей через `/styles/site-background.css`.

Чтобы заменить фон сайта, измените `--app-background-image` в этом файле.
При добавлении нового изображения используйте новый URL, чтобы браузерный
кеш не сохранял предыдущую версию. Для однотонного фона задайте `none`.

Оболочки страниц должны оставаться прозрачными. Карточки, поля, меню и
иллюстрированные секции могут иметь собственные поверхности: это не фон
страницы. Новый статический HTML-документ должен подключать общий CSS.

Mobile, admin-panel и trainer-panel используют свои темы и не входят в эту
схему. Используется изображение неба `site-sky-background-v1.webp`.

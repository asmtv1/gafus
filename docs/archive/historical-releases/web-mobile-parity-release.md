# Синхронизация web с mobile — 3 октября 2026

## Область

Проверены текущие изменённые mobile-экраны и существующие web-реализации: навигация, профиль, подписка, питомцы, чат, консультации, статьи, курсы. Мобильные изображения шапок и подложка нативной панели вкладок не перенесены. Native startup-splash предназначен для запуска Expo; web использует маскот загрузки страниц и запросов. Web сохраняет свою структуру страниц и фоновую текстуру.

## Перенесено и исправлено

- Шесть WebP-иконок основной навигации. Отдельный пункт чата, «Диалоги» для назначенного кинолога. Состояние назначения сбрасывается при смене аккаунта. Закрытие меню по Escape с возвратом фокуса; меню прокручивается на небольшом экране.
- Структура профиля: настройки, данные аккаунта, информация, действия с аккаунтом. WebP-иконки из mobile, Telegram, поддержка и четыре юридических документа. Действия VK, cookies, экскурсии, пароля и удаления сохранены.
- Напоминания вынесены на `/reminders`. Защита повторного создания и пересекающихся сохранений. Снятие последнего дня передаёт `null`, а не `undefined`.
- Подписка: оформление через существующий `/subscription`, преимущества и маскот, бессрочный партнёрский доступ, срок доступа, управление в App Store и обновление статуса. Отмена устаревших запросов статуса и защита повторного действия.
- `/profile` без username получает текущий логин из серверной сессии; ссылки чата на тариф ведут на `/subscription`.
- Питомцы: иллюстрация пустого списка и WebP-кнопки выбора собаки/кошки. Уже существующие web-карточки, вес, документы и процедуры сохранены.
- Чат: личный/общий разделы уже присутствовали. Добавлены отмена устаревших запросов, защита смены аккаунта и выхода со страницы, восстановление сессии после завершения provisioning, блокировка двойного send/upload/start и повторной пагинации. Повтор отправки сохраняет clientMessageId; загрузка проверяет размер/формат, вложение можно убрать из черновика. Отправка по-прежнему проходит через GAFUS API.
- Подключение общего пакета Prisma вынесено из webpack-сборки: сгенерированный клиент и native engine разрешаются вместе из `@gafus/prisma`. Это устраняет ошибку engine и выбор пустого второго экземпляра клиента при сборке web. Pino и thread-stream также оставлены внешними: transport находит настоящий worker-файл из своего пакета.
- Маскот загрузки перенесён в web как анимированный WebP (334 КБ вместо GIF 4,4 МБ), со статичным изображением при prefers-reduced-motion.

## Проверки

- Web: 143 теста, включая 10 новых тестов порядка ответов, смены аккаунта, размонтирования, повторных кликов, retry, файлов и напоминаний.
- Core: 45 тестов чата, вложений, уведомлений и тарифного доступа.
- Live Stream на отдельной локальной тестовой базе и development-ключах: 20 сценариев личного чата и 15 общего. Проверены одновременное создание, retry/idempotency, webhook, unread, настоящие фото/видео, запрет прямой отправки SDK, чужие вложения, истечение/возобновление доступа и модерация. Скрипты удалили свои тестовые данные.
- 28 исходных WebP побайтно совпадают с mobile; шапки исключены. Изображения маскотов дополнительно оптимизированы в WebP.
- Lock-файл проверен frozen install без установки скриптов.
- TypeScript web: пройден.
- Полный ESLint web: 0 ошибок, 110 предупреждений в существующем рабочем дереве.
- `git diff --check`: пройден.
- Production build: пройден, 98 страниц. Собранный standalone-сервер запущен; прежние ошибки Prisma engine, отсутствующего клиента и logger worker не повторяются.
- Браузер: `/profile`, `/reminders`, `/pets`, `/profile/addPet`, `/cynologist-chat` — HTTP 200 на 320, 390 и 1440 px; горизонтального переполнения и pageerror нет. Изображения загружены и просмотрены. Radio собаки/кошки переключаются. Escape закрывает основное меню и возвращает фокус.
- Браузер с настоящим Stream: анкета → первое сообщение → сообщение клиента → ответ кинолога; сообщение общего чата. После окончания подписки история и ответ сохранены, composer отсутствует, продление ведёт на `/subscription`.
- Четыре локальных юридических документа возвращают HTTP 200.
- В меню клиента — «Чат» (`/cynologist-chat`), назначенного кинолога — «Диалоги» (`/cynologist-chats`).
- Временные браузерные аккаунты, личный Stream-канал и их сообщения удалены; авторизационные файлы удалены, временный сервер и браузер остановлены.
- Примеры экранов: `output/playwright/web-mobile-parity-profile-menu-390.png`, `web-mobile-parity-profile-premium-390.png`, `web-mobile-parity-addpet-390.png`, `web-mobile-parity-pets-390.png`.
- Существующие предупреждения CSS/autoprefixer и ESLint не являются ошибками сборки. Проверка `next.config.ts` отдельно выявляет пять ранее существовавших `any`; штатный lint проверяет `src`. В локальной браузерной проверке внешняя телеметрия AppTracer возвращала HTTP 400; это не ошибка API чата или страниц.

## Граница выпуска

Изменения остаются в рабочем дереве. Commit, push, production deployment и production-миграции не выполнялись. Live-проверки выполнены в development Stream, не в production; доставка push на устройстве не проверена. Для включения production-чата сохраняются проверки из `cynologist-chat-release.md`: миграции, настройки Stream/webhook, назначение кинолога, реальные клиентский/тренерский диалоги и доставка push.

# История прежнего Stream Chat

Эти документы относятся к реализации Stream Chat за октябрь 2026 года. Они **не описывают текущую Chat 2.0** и не служат инструкцией для новых изменений. Текущие решения см. в [контракте Chat 2.0](../../contracts/CHAT2_MEDIA_V2.md) и [архитектуре](../../current/ARCHITECTURE.md).

Исторические отчёты оставлены без редакторских изменений.

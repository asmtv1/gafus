# Изолированный прототип Stream Chat

Это технический тест, не интеграция с production GAFUS.

- Web: вход как синтетический клиент/кинолог, переписка и выход.
- Expo: тот же канал, нативные компоненты Stream.
- Backend выдаёт часовые JWT только двум заранее созданным тестовым пользователям.
- Нет проверки тарифов, авторизации GAFUS, SLA или push.
- Прямая отправка разрешена только для теста UI. Production план предусматривает серверную отправку с проверками доступа.

Текущий рабочий проект с установленными зависимостями: `/tmp/gafus-stream-prototype`.
Веб-прототип: http://localhost:8087. Тестовый сервер сессий: 127.0.0.1:4318.

Установка из этой копии: `npm ci --legacy-peer-deps`.
Web: `npm run web`.
Native: `npx expo prebuild`, `npm run ios`. Нужна нативная сборка; Expo Go не подходит.

На iOS Simulator localhost указывает на Mac. На реальном устройстве нужен отдельный доступный защищённый тестовый backend; текущий локальный endpoint не подходит. Не публиковать endpoint с выбором роли.

Для запуска сервера задайте `STREAM_TEST_ENV_FILE` абсолютным путём к локальному файлу с STREAM_API_KEY и STREAM_API_SECRET и запустите `node session-server.cjs`. Файл с секретом не включать в копию или git. Существующий тестовый канал должен быть создан заранее.

Проверено: web отправка/ответ, повторный вход, загрузка PNG и MP4 и полное воспроизведение H264 MP4. Metro export iOS и Android успешен. Статус нативного запуска описан в `docs/stream-chat-preflight.md`.
